# Χειροκίνητες δοκιμές

Λίστα ελέγχου πριν από κάθε commit που αγγίζει την εισαγωγή αποδείξεων.
Τρέξε τις ενότητες που αφορούν αυτό που άλλαξες. Αν άλλαξες κάτι κοινό (π.χ. `money.js`), τρέξε όλες.

**Προετοιμασία (δύο τερματικά):**

| Τερματικό | Φάκελος | Εντολή |
|---|---|---|
| 1 | `grocery-receipts-gr\worker` | `npx wrangler dev` |
| 2 | `grocery-receipts-gr` | `npm run dev` |

**Αρχεία δοκιμών** (στο `receipts-private`, δεν ανεβαίνουν ποτέ στο GitHub):
- `qr-test-crop.png`: το QR της 1ης απόδειξης Μασούτη (7 είδη, 20,69 €, 06/11/2026)
- `masoutis-2.xml`: η 2η απόδειξη Μασούτη (μπανάνες σε κιλά + χαρτί κουζίνας, 3,62 €).
  Ο σύνδεσμος του QR της είναι μέσα στο αρχείο, στο `##INVOICE-URL##`. Παρακάτω τον λέμε `<QR2>`.

Οι πραγματικοί σύνδεσμοι μπαίνουν **μόνο** στη γραμμή διευθύνσεων του browser, ποτέ σε αρχείο του project.

## Α. Worker (στη γραμμή διευθύνσεων του browser)

| # | Σύνδεσμος | Αναμενόμενο |
|---|---|---|
| Α1 | `http://localhost:8787/` | Λείπει ο σύνδεσμος της απόδειξης |
| Α2 | `http://localhost:8787/?url=abc` | Μη έγκυρος σύνδεσμος |
| Α3 | `http://localhost:8787/?url=https://www.google.com` | Άγνωστος πάροχος |
| Α4 | `http://localhost:8787/?url=https://e-invoicing.gr/` | Μη έγκυρος σύνδεσμος |
| Α5 | `http://localhost:8787/?url=<QR2>` | JSON: `chainId` "masoutis", `mark` "400015960635456", μπανάνες `kg`, 1.037, 113, 109 · χαρτί `piece`, 1, 249, 249 |

Μετά από `npx wrangler deploy`: ξανά τα Α3 και Α5 με `https://grocery-receipts-api.christsarch.workers.dev` αντί για `http://localhost:8787`.

## Γ. Εισαγωγή στην εφαρμογή (`localhost:5173` → Νέα απόδειξη)

| # | Ενέργεια | Αναμενόμενο |
|---|---|---|
| Γ1 | 📷 → `qr-test-crop.png` | Σύνδεσμος QR, "Φόρτωση απόδειξης…", μετά "Βρέθηκαν 7 είδη". Αλυσίδα Μασούτης, ημερομηνία 06/11/2026, 7 είδη, **σύνολο 20,69 €** |
| Γ2 | Άλλαξε το **όνομα** των αυγών | Η γραμμή μένει 3,99 €, το σύνολο μένει 20,69 € |
| Γ3 | Άλλαξε την **ποσότητα** των αυγών από 1 σε 2 | Η γραμμή γίνεται 7,98 €, το σύνολο **24,68 €** |
| Γ4 | Ξαναφόρτωσε το `qr-test-crop.png` και πάτα **Αποθήκευση** χωρίς αλλαγές | Η φόρμα και η φωτογραφία καθαρίζουν. Στο **Ιστορικό**: Μασούτης, 06/11/2026, 7 είδη, **20,69 €** |
| Γ5 | F12 → **Application** → IndexedDB → `grocery-receipts` → `receipts` → η απόδειξη του Γ4 | Κάθε είδος έχει `lineTotalInCents` (π.χ. αυγά: 399) |
| Γ6 | Σταμάτα το τερματικό 1 (Ctrl+C) και ξαναφόρτωσε την εικόνα | "Δεν υπάρχει σύνδεση με την υπηρεσία αποδείξεων". Η σελίδα δεν κολλάει |

| Γ7 | Με την απόδειξη του Γ4 αποθηκευμένη, ξαναφόρτωσε το `qr-test-crop.png` | "Αυτή η απόδειξη έχει ήδη αποθηκευτεί". Η φόρμα **δεν** γεμίζει |
| Γ8 | F12 → Application → IndexedDB (↻ για ανανέωση) → η απόδειξη του Γ4 | Έχει πεδίο `mark` (400015950279933) |

Στο τέλος: σβήσε από το Ιστορικό την απόδειξη του Γ4, για να μη μετράει στα πραγματικά σου έξοδα.
